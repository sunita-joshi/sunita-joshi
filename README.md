## Featured Projects

### Traffic Noise Estimation using Sentinel-2 Imagery and DEM

This project was developed as part of my master's thesis. It explores the use of a U-Net-based deep learning model to estimate road traffic noise using Sentinel-2 imagery and Digital Elevation Model data.

The project compares a Sentinel-2-based baseline model with a DEM-integrated model and includes experiments related to terrain influence, simulated barrier walls, shadow-effect behaviour, and model generalization.

**Keywords:** Deep Learning, U-Net, Sentinel-2, DEM, Traffic Noise, Remote Sensing, Geospatial Analysis

---

### Semantic Segmentation of Vegetation Types

This semester project focuses on semantic segmentation of vegetation types from aerial imagery. Training labels were created manually using Label Studio, and a U-Net model was implemented for pixel-wise classification of vegetation and land-cover categories.

The project includes classes such as coniferous trees, broadleaf trees, shrubs, grass and cultivation, and others. One of the main challenges was the visual similarity between vegetation classes based on spectral, textural, and spatial characteristics.

**Keywords:** Semantic Segmentation, U-Net, Aerial Imagery, Label Studio, Vegetation Classification, Deep Learning

---

### Urban Green Space Accessibility Analysis using Open Data

This GIS project analysed the distribution and accessibility of green urban spaces using open geospatial data. The project compared Stuttgart and Accra using green-space, building, and population datasets.

The workflow included Euclidean distance analysis, raster reclassification, AHP-based weighted overlay, building accessibility analysis, and population accessibility analysis.

**Keywords:** GIS, Urban Green Space, Spatial Accessibility, Open Data, ArcGIS Pro, AHP, Weighted Overlay

---

### Topographic Map Preparation using ZY-3 Satellite Imagery

This bachelor thesis project focused on preparing a topographic map at a scale of 1:25,000 using ZY-3 satellite imagery. The work involved geospatial processing steps for extracting and representing spatial information in map form.

**Keywords:** Topographic Mapping, ZY-3 Satellite Imagery, Photogrammetry, GIS, Remote Sensing
